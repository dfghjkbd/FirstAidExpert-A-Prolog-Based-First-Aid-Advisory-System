🩺 FirstAidExpert: A Prolog-Based First Aid Advisory System
Description:

FirstAidExpert is an intelligent expert system that provides first-aid advice based on user-reported symptoms. It integrates Prolog for rule-based reasoning and Flask (Python) for a user-facing web interface. The system supports multilingual users by integrating the Google Translate API (via the googletrans library), allowing automatic translation of symptoms and medical advice.

Features:

🔍 Symptom normalization with alias matching

🧠 Rule-based first-aid reasoning engine (Prolog)

🌐 Multilingual support using Google Translate

📹 YouTube video suggestions for visual instructions
